# Learnings baseline — seeded before the first live-small night

The accumulated good/bad ledger of the project so far. The nightly learning
lane (hermes cron `gridbot-learning`, skill `.hermes/skills/gridbot-learning`)
appends one dated file per night after this.

## What has WORKED (patterns to keep)

- **Verify before trusting, always.** Every external claim we double-checked
  paid: the "US esports empty" read was a pagination artifact; the
  clob-client-v2 repo was a typosquat; the bin-3 count was a transcription
  slip; cross-session row-exact reproduction caught it.
- **Adversarial review with real teeth.** ox-alpha's 10 findings on the
  live-fire path were ALL real (cancel abandonment, create-retry
  double-order, ambiguous acks, monotonic exposure counter...). Zero false
  positives. Multi-agent review both directions (glm audited us, we fixed
  glm's dead-loop in us_mapping and the CWD-relative path in sizing).
- **Pre-registration discipline scales.** Freezing H-MAPENTRY1's formula +
  bar BEFORE building the instrument took ~20 minutes and permanently
  removes the temptation to fit the bar to the result.
- **Record the denominator.** mapentry logs every skip (no mapping, no
  book, OT domain) — the starvation clause is decidable because refusals
  are data.
- **Fail-closed everything.** Arming gate reasons, wire refusals before
  client construction, caps clamped in code, post-only at the exchange.
  None of these have produced a false-positive trade path.
- **Small pure functions + brute-force cross-checks.** race_win_prob is
  verified against an independent recursion; quant math has 25 tests.
- **Live calibration proof beats backtests**: MODELENTRY thresholds
  0.806/.865/.928 observed vs 0.807/.866/.920 forecast (n=1,613).

## What FAILED or bit us (patterns to avoid)

- **Silent empties are the worst failures.** The 22:30 analysis wrote a
  0-char report with exit 0 (Claude-5 thinking consumed max_tokens; 200 OK,
  no text). Fix: bigger budget + retry + RAISE on empty. Rule: an empty
  output is an error unless proven intentional.
- **OS state beats daemons.** KDE idle-suspend slept the box 10.8h; capture
  went dark; missed timers fired at once and produced a misleading "quiet
  night" digest. Daemons need systemd-inhibit for sleep; digests need
  wall-clock sanity checks.
- **Batch/pagination blindness.** events.list buried esports under
  stick-and-ball sports; Follow.lines() caps at 1000/call (replay smoke
  undercounted). Always ask "what does this API NOT return by default?"
- **A test that touches the real venue is a bug even if it passes.** A
  placeholder assert called real cancel with real keys (caught within
  minutes by suite-time jump 0.15s→6.7s). Wire modules get stubbed clients
  in tests, no exceptions.
- **Key-name drift between doc and code.** LIVE_FIRE.md described a gate
  (PRIVATE_KEY/FUNDER) that no longer existed. Docs describing safety
  systems must be updated in the same commit as the system.
- **Don't touch a co-agent's in-flight files.** A mid-air edit collision
  with glm's live session lost 2 of 3 edits; stay out of files another
  agent is actively editing, coordinate through the board.
- **Relative paths under systemd.** sizing's CWD-relative config path would
  silently fall back to defaults as a daemon. Anchor to config.DATA_DIR.
