# docs/history — the dated record

Everything here is historical. It is kept verbatim because it is how the
current system came to be, and because several current rules cite it. Nothing
here is a live plan or a current claim. For those, read `docs/STATE.md`,
`docs/WORKBLOCKS.md` and `docs/FALSIFICATION.md`.

| path | what it is |
|---|---|
| `STATE-2026-08-26-to-2026-10-16.md` | the running state narrative from the first armed night to the 2026-10-16 baseline (dated addenda, never edited) |
| `learnings/` | nightly operator notes, 2026-08-26 → 09-03 |
| `analysis-managed/` | drafts from the LLM analyst that was removed on 2026-10-16. They were draft-only and never verdicts |
| `specs/` | design briefs that are implemented, superseded, or belong to closed lanes |
| `amendments-2026-08-27-draft.md` | amendment drafts that were never registered |

**Path drift.** These files cite paths as they were when written:
`docs/superpowers/specs/…` (now `docs/history/specs/` or `docs/specs/`),
`docs/learnings/…` (now `docs/history/learnings/`), `docs/STATE.md` (now the
`STATE-…` file here), and scripts that were removed from `main` on 2026-10-28.
Every one of those scripts runs from tag `evidence-2026-10`.
